## Безопасность: доступ к логам

Доступ к логам приложения должен быть ограничен: только уполномоченный персонал (операторы, DevOps) должен иметь возможность читать логи. Рекомендуется: отдельный каталог/файлы для логов с правами доступа, исключающими чтение посторонними (например, `chmod 0600` для файлов логов), и настройка политик доступа в среде развёртывания (Kubernetes, Docker, ОС).
